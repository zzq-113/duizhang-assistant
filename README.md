# 清核对账助手

一款在浏览器本地运行的订单与收款自动对账工具，面向财务、电商运营、行政和小微企业。

## 功能

- 读取 XLSX、XLS、CSV、TSV 文件
- 选择工作表、表头行、匹配编号和金额字段
- 按编号汇总同一文件中的多行记录
- 识别核对一致、未收到款、额外收款、金额差异和重复编号
- 支持金额误差设置和结果筛选
- 导出包含概览、完整明细、异常明细和原始数据的 Excel 报告
- 文件仅在浏览器本地处理，不上传服务器
- 对导出内容进行公式注入防护

## 在线使用

公开网址：<https://zzq-113.github.io/duizhang-assistant/>

打开网页后，可以上传自己的两张表，也可以点击“加载演示数据”体验。演示结果为：7 个唯一编号、2 个核对一致、5 个需要处理，总金额差 -900 元。

网页不需要安装软件，文件仅在浏览器中处理。正式处理数据前，请先使用少量脱敏样表确认业务规则。

## 客户接单需要确认

1. 客户提供两张脱敏样表。
2. 明确两张表的匹配字段和金额字段。
3. 确认拆单、合并付款、退款、手续费和允许误差规则。
4. 用少量已知结果完成验收，再处理完整数据。
5. 正式交付前替换品牌、使用说明和导出模板。
